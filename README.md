# Karasu website starter

Static GitHub Pages site for Karasu.

## Publish
1. Create a GitHub account. Try the username `karasuguide`; if unavailable, use `karasu-guide` or another close variant.
2. Create a public repository named `<your-username>.github.io`.
3. Upload all files and folders from this package to the repository root.
4. In Settings > Pages, set the publishing source to the `main` branch / root if GitHub has not enabled it automatically.
5. Open `https://<your-username>.github.io/` after deployment.

Before applying to PartnerStack, verify every page loads and the Contact email is correct.
